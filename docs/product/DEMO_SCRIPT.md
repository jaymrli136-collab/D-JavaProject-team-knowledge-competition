# 比赛演示脚本

## 1. 项目知识总览

以 `u_alice` 登录，展示番茄小说和红果短剧两个项目，以及 ACTIVE 文档、待确认记忆、开放缺口和最近评测指标。

## 2. 单项目风险问答

提问：“番茄小说增长实验当前最大的风险是什么？”

展示结论式回答、项目 / 文档 / 章节 / 版本引用、引用覆盖率和 SSE 执行阶段。

## 3. 原文下钻

点击证据“查看原文”，展示命中的完整章节并高亮当前证据片段。

## 4. 会话追问

继续提问：“那它具体怎么处理？”

展示 rewrite Trace、上下文查询、证据和会话范围继承。

## 5. 跨项目对比

同时选择番茄小说和红果短剧，提问：“比较两个项目当前最大的风险。”

展示每个项目至少一条证据，以及“非项目成员不可见”的权限边界。

## 6. 记忆治理

对可信回答点击“沉淀候选记忆”，填写轻量摘要，提交后进入“记忆”页。

展示待确认、确认启用、撤回和来源 evidenceId。确认后的记忆会在后续回答中作为软上下文出现，但不能替代引用。

## 7. 知识缺口与摄入联动

提问知识库不存在的问题，例如：“番茄小说在南极洲的用户覆盖率是多少？”

展示拒答、自动记录知识缺口、重复问题次数累计；随后录入包含“南极洲用户覆盖率”的文档，缺口进入“待复核”并关联候选文档。

## 8. 评测与安全

运行固定评测，展示通过率、引用覆盖、拒答准确率、权限违规和最近趋势。

最后说明：文档证据被视为不可信数据，提示注入片段不会改变权限、工具或系统规则。
