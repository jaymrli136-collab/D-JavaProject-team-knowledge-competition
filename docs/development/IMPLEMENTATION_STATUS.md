- Session Memory 连续追问和项目范围继承。

- ACTIVE 记忆软上下文召回：按问题与项目范围匹配，记录到 AskResponse 和 Trace，不替代引用。
- 知识缺口闭环：拒答自动记录、相同问题累计、解决/忽略、一键预填补录和 Markdown 导出。

- 证据下钻：Evidence 携带文档与章节 ID，详情接口返回完整原文与生命周期状态。
- 固定评测历史：保存通过率、引用覆盖、证据召回等指标，前端展示最近六次趋势。
- 固定评测用例接口：公开问题、期望状态、答案/证据关键词与项目范围。
- 单次引用覆盖率：按实质陈述统计带引用比例，前端和 Trace 同步展示。
- 知识健康总览：聚合文档、记忆、缺口、最近评测、反馈量和有帮助率。
- 运行审计：最近运行列表展示状态、耗时与时间，点击可回放证据和 Trace；聚合总运行数、P95 耗时与平均引用覆盖。
- 缺口与摄入联动：新文档命中开放缺口后进入待复核并关联候选文档。
- 提示注入防护：证据清洗与不可信内容边界，防止文档改变系统规则。
- 运行取消令牌：前端 AbortController、SSE 断开/超时后在阶段边界停止后续执行。
- 回答反馈：按 runId 去重保存、前端提交和正向率汇总。
- 多轮查询改写：短追问融合上一轮问题，Trace 记录上下文查询。
- 项目管理：创建项目、负责人维护成员，前端提供创建入口和用户目录建议。
- 项目角色：OWNER / EDITOR / VIEWER 校验、角色 API、持久化、成员映射和只读前端控件禁用。
- 项目归档：前端导出 JSON、导入为新项目；文档/章节/决策 ID 重映射，记忆重置为候选。
- 运行时持久化：5 秒周期 JSON 快照、原子替换、启动恢复和测试隔离。
- Docker Compose：多阶段镜像、D 盘代码项目、挂载 data 持久化卷。
- 知识录入：Markdown/TXT 本地读取；PDF/DOCX 服务端解析并复用摄入、版本与缺口联动。
- 检索预览：前端和 API 均可不调用生成模型，查看 intent、queries、memoryHints 和 evidence。
- 查询规划与引用校验单元测试：覆盖意图分类、非法引用剔除和低覆盖告警。
- 安全基线：CSP、nosniff、frame deny、no-referrer 与 API no-store。
- 请求链路：统一 X-Request-Id、MDC 日志字段与响应头。
- Actuator 知识健康：项目数、ACTIVE 文档、开放缺口、模型与 Embedding 模式。
- 运行预算：限制最大证据数与单次运行时长，超限停止后续阶段。
- 固定评测集：事实、跨项目比较、决策、上线时间、无答案、越权。
- 响应式原生前端：用户切换、项目选择、问答、证据、轨迹、知识录入和评测。
- Spring Boot 集成测试、Harness 单元测试和项目记忆治理测试。
- D 盘 Maven 配置与启动脚本。

## 本地工具链

系统 PATH 未提供 Maven，项目脚本优先使用 `.tools/apache-maven-3.9.11`，本地仓库固定为项目内 `.m2`：

```powershell
.\scripts\test.ps1
.\scripts\run.ps1
```

首次执行如本地仓库缺少依赖，Maven 会从中央仓库下载到项目内 `.m2`；依赖齐备后可使用 `-o` 离线执行。
